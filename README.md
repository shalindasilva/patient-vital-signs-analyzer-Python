# patient-vital-signs-analyzer-Python
A beginner-friendly Python project for analyzing basic patient vital signs and practicing medical data processing.

## Project Overview

This project demonstrates how Python can be used to collect and analyze basic
patient vital-sign measurements.

The program accepts:

- Patient name
- Age
- Heart rate
- Body temperature
- Oxygen saturation (SpO2)
- Systolic blood pressure
- Diastolic blood pressure

It compares the entered values with predefined educational reference ranges
and displays the results.

## Technologies

- Python
- Conditional statements
- Variables
- User input
- Basic calculations
- Formatted output

## Learning Objectives

This project was developed to practice:

- Python variables
- Data types
- `input()`
- `if / elif / else`
- Comparison operators
- Logical operators
- f-strings
- Basic medical-data processing
